# 求職簡歷自動投遞系統 — 數據模型設計

- 文檔版本：v0.1
- 數據庫：Supabase Postgres（免費 500MB）；附件不入庫
- 約定：所有業務表含 `created_at/updated_at`；所有用戶數據表啟用 RLS（`user_id = auth.uid()`）；密碼/Cookie 一律加密字段，後綴 `_enc`

## 1. 實體關係總覽

```
auth.users ─1:1─ profiles ─1:1─ user_settings
                 │
                 ├─1:N─ platform_accounts（加密）
                 ├─1:N─ user_documents
                 ├─1:N─ resume_versions ──N:1── user_documents
                 ├─1:N─ candidate_profiles（畫像，多版本）
                 ├─1:N─ watched_companies
                 ├─1:N─ job_matches ──N:1── job_postings（全局）
                 ├─1:N─ applications ──N:1── job_postings
                 │         ├─1:N─ application_attempts
                 │         └─1:N─ manual_tasks
                 └─1:N─ notifications
全局: job_postings / companies_catalog / audit_logs / collect_jobs / ai_jobs / adapter_health
```

## 3. RLS 策略速查

| 表 | 策略 |
|---|---|
| 除 job_postings/companies_catalog/adapter_health/audit_logs 外全部業務表 | `using (auth.uid() = user_id)` |
| profiles | 自己可讀寫；admin 可讀全部（`role='admin'`） |
| job_postings | 所有登錄用戶可讀（用於瀏覽）；寫入僅服務端（service_role 繞過 RLS） |
| key_wraps / audit_logs / adapter_health | 僅 service_role / admin |
| 刪除 | 一律軟刪除（deleted_at），不物理刪（審計） |

## 4. 索引要點

- job_postings：UNIQUE(source, external_id)；`(is_active, first_seen_at desc)`；`catalog_company_id`。
- job_matches：UNIQUE(user_id, posting_id)；`(user_id, status, match_score desc)`。
- applications：UNIQUE(user_id, posting_id)；`(status, next_retry_at)`（重試掃描）。
- manual_tasks：`(status, expires_at)`。
- notifications：`(status, created_at)`。
