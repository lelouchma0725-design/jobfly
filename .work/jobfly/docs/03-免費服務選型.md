# 求職簡歷自動投遞系統 — 免費服務選型（已核實）

- 文檔版本：v0.1（2025 年核實；額度以各平台最新公告為準，實現前會再次 web 核實）
- 原則：全部組件在免費層內運行；唯一主要變動成本 = LLM token 費

## 1. 數據庫：Supabase Free ✅（已選定）

核實來源：[Supabase Pricing](https://supabase.com/pricing.md)

| 項 | 免費額度 |
|---|---|
| 數據庫 | 500 MB / 項目 |
| 文件存儲 | 1 GB（單文件 ≤50MB） |
| API 請求 | 不限量 |
| 月活用戶 | 50,000 |
| 出口流量 | 5 GB |
| 項目數 | 2 個（dev + prod 剛好） |
| ⚠️ 休眠 | 1 週無活動自動暫停 → 用 UptimeRobot 每日心跳保活 |

## 2. 附件存儲：Cloudflare R2 ✅（簡歷/成績單/簽證等）

- 10 GB 免費 + **無出口流量費** + 簽名直傳（前端直傳繞過後端）。
- Supabase Storage 1GB 作為小文件/預覽備用。
- 備選：Backblaze B2（10GB 免費）。

## 3. 推送渠道（FR-1h / FR-3c）

### 3.1 微信推送（無官方免費 API，選第三方）

| 渠道 | 免費額度（已核實） | 特點 | 決策 |
|---|---|---|---|
| [PushPlus](https://www.pushplus.plus/use.html) | 實名用戶微信服務號渠道：單日 <200 次正常推送，200–2000 次當日停推次日恢復 | 一對一/群組推送、支持郵件/企業微信/釘釘/飛書多渠道 | ✅ 主渠道（用戶自助填 token） |
| Server酱（舊版 sc.ftqq.com） | ⚠️ 已公告**分期下線** | 不再推薦 | ❌ |
| 企業微信群機器人 | Webhook **完全免費、無每日條數限制** | 用戶需加入企業微信群；適合系統級批量推送 | ✅ 管理員/批量渠道 |
| 郵箱 SMTP | Brevo 免費約 300 封/天；QQ/163 郵箱 SMTP 授權碼免費（有頻率限制） | 兜底渠道，支持 HTML 郵件 | ✅ 兜底渠道 |

### 3.2 決策

- 用戶級：PushPlus token（微信收消息，用戶掃碼自助綁定，token 加密存儲）。
- 系統級/管理員告警：企業微信機器人。
- 兜底：郵箱 SMTP。
- FR-3c「直接框回填」：微信/郵件都無法在消息內直接填表 → 推送帶 H5 短連結，跳轉系統頁面填寫（見《01-架構設計》4.4）。

## 4. 其他組件

| 組件 | 選型 | 免費額度 | 用途 |
|---|---|---|---|
| 部署 | Render / Railway | 免費 Web Service（冷啟動、每月有限時長） | 後端 + 前端靜態 |
| 保活 | UptimeRobot | 免費監控 5 分鐘間隔 | 防休眠/冷啟動 |
| 任務隊列 | 自研 DB 隊列（collect_jobs 表） | 0 成本 | 免 Redis；後續量大再上 Upstash 免費 Redis |
| 瀏覽器自動化 | Playwright + Chromium（服務器內置） | 0 成本 | 採集 + 投遞 |
| OCR | PaddleOCR（開源） | 0 成本 | 僅掃描版 PDF/圖片兜底；數字版 PDF 直接抽文本，不用 OCR |
| LLM | DeepSeek / OpenAI 兼容 API（可插拔） | 按量計費 | 解析/畫像/匹配/微調；ai_jobs 表統計 token 與費用 |
| 短連結 | 自建（`/h5/{task_id}`） | 0 成本 | H5 回填頁，不需要第三方短鏈服務 |

## 5. 月成本估算（免費層內）

| 項 | 成本 |
|---|---|
| Supabase + R2 + Render + UptimeRobot + 企業微信 + Brevo | $0 |
| PushPlus | $0（實名，200 次/日內） |
| LLM | 唯一變動成本：估算每人每月畫像+匹配+微調 ≈ 數萬 token；以 DeepSeek 定價約人民幣數元/人/月，由管理員自備 API key |

## 6. 風險與降級

| 風險 | 降級方案 |
|---|---|
| PushPlus 實名門檻 | 用戶可選郵箱渠道；管理員可開企業微信 |
| Supabase 500MB 滿 | 崗位描述 raw 壓縮存儲；定期清理 90 天前失效崗位；滿後升級 Pro($25/月) 或自建 |
| Render 免費冷啟動 | 每日心跳 + 用戶感知的「啟動中」提示 |
| 免費層自動化時長耗盡 | 投遞速率限制（每用戶 ≥5 分鐘/次） |
