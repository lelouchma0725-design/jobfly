# 法律文件草案（用戶協議 / 隱私政策 / 代投授權書）

> ⚠️ 本文檔為技術草案，供產品與法務參考。正式上線前請由專業律師審閱，
> 並結合運營主體所在地法律（中國大陸《個人信息保護法》《網絡安全法》、
> 香港 PDPO、GDPR 等）調整。註冊時必須強制勾選同意並記錄 `tos_accepted_at`。

## 一、用戶協議要點

1. **服務性質**：平台為求職者提供崗位信息聚合、匹配分析與自動投遞輔助服務；
   不保證投遞成功率、不保證錄用結果。
2. **自動化風險告知**（重點條款）：
   - 用戶知悉並同意平台使用其提供的賬號憑據在第三方招聘平台/公司官網執行
     登錄、瀏覽、填寫表單、上傳文件、提交申請等自動化操作；
   - 第三方平台可能禁止自動化操作，**存在賬號被限制、凍結、封禁的風險**，
     用戶自擔該風險；平台僅承諾以合理謹慎方式（擬人化頻率、速率限制）執行；
   - 用戶不得利用本服務進行任何違法行為（虛假簡歷、重複惡意投遞、爬取侵權數據等）。
3. **賬號安全**：用戶須對自己保管的平台賬號密碼負責；平台以加密方式存儲，
   但無法保證絕對安全；發現異常應立即修改密碼並通知平台。
4. **AI 內容聲明**：AI 生成的簡歷微調、Cover Letter、畫像分析僅供參考，
   最終投遞前用戶有義務核對；因用戶未核對造成的損失平台不承擔。
5. **服務變更**：平台保留調整免費額度、功能、停止服務的權利（提前公告）。

## 二、隱私政策要點

1. **收集的信息**：賬戶信息（郵箱/手機）、上傳文件（簡歷/成績單/簽證等，
   含敏感個人信息）、第三方平台賬號憑據、瀏覽行為與投遞記錄。
2. **使用目的**：賬戶認證、崗位匹配、自動投遞、消息推送、服務改進。
3. **存儲與保護**：
   - 第三方平台賬號密碼以 AES-256-GCM 信封加密存儲，明文不落庫；
   - 附件存儲於對象存儲（R2），傳輸加密（TLS）；
   - 訪問控制：行級權限隔離，用戶只能訪問自身數據；管理員訪問留審計日誌。
4. **共享**：除用戶明確授權的投遞操作（將簡歷等提交至用戶選擇的招聘方）外，
   不對外共享；不向廣告商出售數據。
5. **用戶權利**：查閱、更正、刪除、導出個人數據；註銷賬號（軟刪除，30 天冷靜期）。
6. **保存期限**：賬號存續期間；註銷後 90 天內刪除或匿名化（法律要求保留的除外）。
7. **未成年人**：服務面向年滿 18 周歲用戶。

## 三、自動投遞授權書（單獨強制勾選）

> 授權人（用戶）特此確認並授權：

1. 授權平台使用授權人提供的招聘平台賬號憑據，代為執行登錄、崗位檢索、
   申請表填寫、文件上傳、申請提交等操作；
2. 知悉平台將加密存儲上述憑據，並僅在執行授權操作時解密使用；
3. 知悉自動化操作可能導致第三方平台對授權人賬號採取限制措施，風險自擔；
4. 授權平台在投遞前按授權人設定的開關，使用 AI 對簡歷與 Cover Letter
   進行**不新增事實**的微調，並保留原始版本可回溯；
5. 授權範圍可隨時在「投遞設置」中關閉或撤回，撤回不影響已完成的投遞；
6. 本授權自勾選同意之日起生效，至賬號註銷或授權撤回之日終止。

## 四、上線配套事項

- 註冊頁/登錄頁：三份文件分開勾選（協議、隱私政策、代投授權），記錄時間戳；
- 「平台帳號」添加表單：再次彈出代投授權書摘要 + 風險提示；
- 設置頁「全自動投遞」開關旁：固定展示風控風險提示文案；
- ICP/備案與應用商店合規（若在中國大陸運營）：網站備案、必要時等保測評。
