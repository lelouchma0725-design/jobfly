# JobsComing RPA 填報助手（Chrome 擴展）

在無法突破招聘官網登錄校驗（圖形驗證碼等）的前提下，最大程度減少你的手動操作：
**你只負責「登錄 + 找到申請頁 + 檢查提交」，所有打字、下拉選擇、簡歷上傳由本擴展自動完成。**

## 安裝（2 分鐘）

1. Chrome 地址欄輸入 `chrome://extensions`
2. 右上角打開「開發者模式」
3. 點「載入未封裝項目」，選擇本目錄（`chrome-extension/`）
4. 固定擴展圖標方便使用

## 使用流程（以中信證券為例）

1. 在 **JobsComing 網站**確認待處理任務已生成（投遞已觸發）
2. 在 **careers.citics.com** 用手機號登錄（圖形驗證 + 短信碼，這一步只有你能做）
3. 打開目標崗位的**申請頁面**（在列表裡點「申請/投遞」進入表單頁）
4. 點工具欄上的擴展圖標 → 面板裡點對應任務的「**開始填報此頁**」
5. 擴展自動：拉取 JobsComing 的填寫方案 → 匹配並填寫所有姓名/手機/郵箱/薪資/技能/經歷/教育欄位 → 上傳簡歷文件 → 高亮已填欄位
6. 你**檢查一遍**（綠色高亮 = 已自動填）→ 點官網「提交」
7. 回擴展面板點「**我已檢查，標記為已投遞**」→ JobsComing 記錄完成

## 工作原理（RPA 鏈路）

- 資料源：JobsComing 元信息表 + 畫像 + 簡歷（用戶在網站上維護一次，處處復用）
- 填報引擎：分析頁面表單（label/placeholder/name）與填寫方案字段做相似度匹配
- 事件模擬：使用原生 setter + input/change 事件（兼容 Vue/React 等框架的雙向綁定）
- 文件上傳：擴展後台代持下載簡歷 → DataTransfer 塞入 file input
- 狀態回傳：完成後通知 JobsComing 標記已投遞

## 支持的網站

- 中信證券 careers.citics.com ✅
- 國泰海通 hr.gtht.com ✅
- Greenhouse / Lever（國際 ATS）✅（通用字段匹配）
- 其他官網：通用字段匹配引擎會盡力而為

## 安全

- 密碼僅用於登錄 JobsComing 換取 token，存於瀏覽器本地存儲，不上傳第三方
- 所有資料傳輸走 HTTPS；擴展僅在配置的招聘網站域名上運行
